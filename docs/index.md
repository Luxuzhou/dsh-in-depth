# 深入理解 DeepSeek Harness

设计原理、源码解读、插件生态与工程实践。

```text
DSH 应用 = 插件树 + Agent Loop + 会话事件 + 能力接缝 + 产品界面
```

这不是“安装后点几下”的产品说明，也不是逐文件翻译官方文档。本书试图回答四个持续有效的问题：

1. DSH 为什么选择“万物皆插件”？
2. 一轮 Agent 任务如何从用户输入走到模型、工具和持久会话？
3. Plugin、Skill、MCP、Workflow 和业务服务分别应该承担什么？
4. 如何把一个能跑的 Demo 变成可审计、可回归、可部署的企业应用？
