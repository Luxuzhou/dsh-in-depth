# 面试题索引

## 基础

1. Harness与模型SDK有什么区别？
2. 为什么工具调用需要Agent Loop？
3. Turn与Step分别解决什么问题？
4. Plugin、Bundle和Profile有何区别？
5. Skill与MCP分别适合什么能力？

## 架构

1. Cordis Context为什么支持可替换Provider？
2. 如何设计Definition、Provider和Consumer三层？
3. 为什么模型可见上下文必须可从会话日志重建？
4. Web多用户部署比本地Web增加了哪些系统问题？
5. 如何隔离DSH快速迭代对业务接口的影响？

## 可靠性与安全

1. 工具超时后进程仍在运行会造成什么问题？
2. 审批凭证为什么要绑定计划哈希？
3. 只读数据库账号为何仍可能产生安全与稳定性风险？
4. 如何审查一个带安装脚本的社区插件？
5. 如何从会话事件判断失败发生在模型、工具还是业务解释层？

## 开放设计题

1. 设计支持跨轮修改条件的Data Agent。
2. 设计可在本机与远程沙箱切换的代码执行能力。
3. 设计DSH企业插件市场及供应链门禁。
4. 设计一个多实例Agent服务的运行所有权与故障恢复机制。
5. 设计DSH升级的回放、灰度、指标和回滚方案。

回答设计题时先声明目标、边界和不变量，再画数据流与失败流，最后说明如何验证。不要直接罗列技术名词。
